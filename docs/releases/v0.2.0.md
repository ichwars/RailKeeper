# RailKeeper v0.2.0

## Deutsch

v0.2.0 bündelt die Modernisierung seit v0.1.22 in einem stabilen Update für bestehende
lokale Installationen. Fahrzeugbestand, Zubehör, Ausstellungen, Dateien, Decoder/CV,
Wertentwicklung und die bisherigen Integrationen bleiben erhalten.

- **Datenerhalt und Wiederherstellung:** Geprüfte Aktualisierung bestehender Installationen,
  Kompatibilitätsprüfung vor Restore und unveränderte Trennung zwischen Sammlungsbackup
  und lokaler Anmeldung. Bestehende Benutzer und Konfiguration werden beim Update erhalten.
- **Decoder und Wertentwicklung:** Eigene Fachmodule, getrennte Decoder-Konfigurationen und
  Arbeitsstände, sichere Vergleichs- und Importabläufe, nachvollziehbare CV-Historien und
  manuelle Bewertungen mit Korrekturen, Stichtagen und getrennten Währungen. Unbekannte Werte
  werden nicht als null oder als nachgewiesene historische Preise dargestellt.
- **Digitalzentralen:** Der zuletzt eingelesene Stand bleibt bis zum nächsten Einlesen erhalten.
  Lesen, Vergleichen und ausdrücklich bestätigtes Übernehmen bleiben getrennte Schritte.
  Schreibvorschau und Bestätigung behalten ihre Berechtigungs-, Frische- und Konfliktprüfungen.
- **Sicherheit:** Die seit v0.1.22 eingeführten Verbesserungen für Anmeldung, begrenzte
  Passwortprüfungen, wiedererkannte Browser, TOTP-Replay-Schutz, Rollen, CSRF, Cookies,
  Uploads und lokale Dateizugriffe sind Bestandteil dieses stabilen Releases.
- **Oberfläche:** Einheitliche eigene Steuerelemente, lokale Schriften und vorhandene
  Design-Tokens, verbesserte schmale Ansichten, sichtbare Beschriftungen der globalen
  Seitenleistenaktionen und kurze, vollständig erläuterte Suchfelder. Fehler lassen sich
  erneut versuchen, ohne den aktuellen Entwurf oder die Arbeitsansicht vorschnell zu verlieren.
- **Codequalität:** Kleinere fachliche Go-/Frontend-Module, kompatible API-Fassade, verbindliche
  Größen- und Architekturprüfungen, stärkere API-Vertragstests und typsichere Prüfung
  unbehandelter Promises. Go 1.27.3 ist für Modul, CI, Linter und alle Builds vereinheitlicht.

Vor einem Update die vorhandene Datensicherung prüfen. Den vorhandenen Datenordner und
lokale Konfiguration weiterverwenden. App-Backups enthalten bewusst keine Benutzer,
Passwörter oder Sitzungen; eine vollständige Installationssicherung bleibt davon getrennt.
Windows-ZIP und Docker-Images für AMD64 und ARM64 gehören zu diesem Release.

## English

v0.2.0 brings the modernization since v0.1.22 to existing local installations as a stable
update. Vehicles, accessories, exhibitions, original files, decoder/CV data, valuations
and existing integrations are retained.

- **Preservation and restore:** Verified upgrades of existing installations, compatibility
  checks before restore and the established separation between collection backups and
  local authentication. Existing users and configuration are retained during an update.
- **Decoders and valuations:** Dedicated domain modules, separate decoder configurations and
  working copies, guarded comparison/import workflows, traceable CV history and manual
  valuation corrections with effective dates and separate currencies. Unknown values are
  not presented as zero or as verified historical market prices.
- **Command stations:** The most recently read result remains available until the next read.
  Reading, comparison and explicitly confirmed adoption remain separate operations. Write
  previews and confirmation retain their permission, freshness and conflict checks.
- **Security:** Login hardening, bounded password verification, recognized browsers, TOTP
  replay protection, roles, CSRF, cookies, upload controls and private file access introduced
  since v0.1.22 are included in this stable release.
- **Interface:** Consistent application controls, local fonts and existing design tokens,
  improved narrow layouts, visible sidebar action labels and concise search fields with
  complete descriptions. Retryable failures retain drafts and the current workspace.
- **Code quality:** Smaller domain-specific Go/frontend modules, a compatible API facade,
  enforced size and architecture guards, stronger HTTP contract tests and typed unhandled
  promise checking. Go 1.27.3 is aligned across the module, CI, analyzer and all builds.

Check the existing backup before updating. Continue using the existing data directory and
local configuration. Collection backups intentionally exclude users, passwords and sessions;
a complete installation backup remains a separate operation. The Windows ZIP and Docker
images for AMD64 and ARM64 are part of this release.
