# RailKeeper v0.1.20.1

## Deutsch

RailKeeper 0.1.20.1 erweitert die sichere Arbeit mit Fahrzeugsets, Importen und ECoS-Digitalzentralen.
Fahrzeugsets können ein eigenes Hauptbild erhalten, das im Bestand, auf Mobilgeräten und in den
Setdialogen konsistent verwendet wird. Sicherungen verwenden Formatversion 20 und bewahren diese
Zuordnung.

Import- und Exportprofile werden gemeinsam und eindeutig nach Richtung dargestellt.
Fahrzeug-CSV-Dateien unterstützen alle 62 Transferfelder sowie geprüfte, dauerhaft speicherbare
Spaltenzuordnungen. Teilimporte bewahren vorhandene, nicht zugeordnete Werte. Ungültige
Wahrheitswerte, offene Zuordnungen und widersprüchliche Profilangaben werden vor der Übernahme
abgewiesen. CSV-Schutzzeichen und ältere JSON-Pakete bleiben verlustfrei kompatibel.

Der Digitalzentralen-Arbeitsbereich liest und übernimmt ECoS-Lokomotiven robuster. Kontrollierte
Schreibabläufe können nach ausdrücklicher Freigabe fehlende Lokomotiven anlegen, erkennen Konflikte
und verifizieren das Ergebnis direkt am Gerät.

Weitere Details stehen im
[deutschen Änderungsprotokoll](https://github.com/ichwars/RailKeeper/blob/v0.1.20.1/CHANGELOG.de.md).

## English

RailKeeper 0.1.20.1 improves safe workflows for vehicle sets, imports, and ECoS command stations.
Vehicle sets can have a dedicated main image that is used consistently in inventory, mobile views,
and set dialogs. Backups use format version 20 and preserve this assignment.

Import and export profiles are shown together with an explicit direction. Vehicle CSV files support
all 62 transfer fields and reviewed column mappings that can be saved for reuse. Partial imports
preserve existing unmapped values. Invalid boolean literals, unresolved mappings, and contradictory
profile data are rejected before apply. CSV protection markers and older JSON packages remain
losslessly compatible.

The Digital centers workspace reads and adopts ECoS locomotives more reliably. After explicit
authorization, controlled write workflows can create missing locomotives, detect conflicts, and
verify the result directly on the device.

See the
[English changelog](https://github.com/ichwars/RailKeeper/blob/v0.1.20.1/CHANGELOG.md)
for details.
