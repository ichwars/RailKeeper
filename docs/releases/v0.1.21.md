# RailKeeper v0.1.21

## Deutsch

v0.1.21 veröffentlicht die seit v0.1.20.4 auf `main` zusammengeführten Abhängigkeitsupdates und
Sicherheitsprüfungen. Go und SQLite sowie React, Lucide, Vite, Vitest und die zugehörigen Build-
und Testpakete sind aktualisiert. Das Frontend-Paket verwendet explizit ES-Module; Dependabot
aktualisiert Vitest und seine Begleitpakete gemeinsam.

Die Frontend-Sperrdatei behebt bekannte Undici-Sicherheitslücken. Abhängigkeits-Pull-Requests
führen Go- und npm-Sicherheitsprüfungen aus, einschließlich der npm-Entwicklungsabhängigkeiten.
Docker-Images werden vor dem Merge lokal gebaut und mit Trivy geprüft. Aktualisierte,
SHA-gepinnte GitHub Actions einschließlich CodeQL ergänzen diese Prüfungen.

Die Laufzeit meldet Version 0.1.21. Docker-Installationsbeispiele und Versionsmetadaten der
Dokumentation folgen diesem Release. Die Änderungen seit v0.1.20.4 betreffen Abhängigkeiten,
Builds und Sicherheitsprüfungen; Datenbankmigrationen und Backupformat bleiben unverändert.

Weitere Details stehen im
[deutschen Änderungsprotokoll](https://github.com/ichwars/RailKeeper/blob/v0.1.21/CHANGELOG.de.md).

## English

v0.1.21 releases the dependency updates and security checks merged into `main` since v0.1.20.4.
Go and SQLite, React, Lucide, Vite, Vitest, and their build and test packages are updated. The
frontend package explicitly uses ES modules; Dependabot updates Vitest and its related packages
together.

The frontend lockfile addresses known Undici vulnerabilities. Dependency pull requests run Go
and npm vulnerability checks, including npm development dependencies. Docker images are built
locally and scanned with Trivy before merging. Updated, SHA-pinned GitHub Actions, including
CodeQL, complement these checks.

The runtime reports version 0.1.21. Docker installation examples and documentation version
metadata follow this release. Changes since v0.1.20.4 concern dependencies, builds, and security
checks; database migrations and the backup format remain unchanged.

See the
[English changelog](https://github.com/ichwars/RailKeeper/blob/v0.1.21/CHANGELOG.md)
for details.
