# RailKeeper v0.3.0

## Deutsch

- **Zubehörsets mit Inhalt.** Gleissets und andere Zubehörpakete lassen sich ohne Fahrzeug erfassen. Jede Position hat eine Bezeichnung und eine Stückzahl je Set. Der Lagerbestand zählt vollständige Sets.
- **Fahrzeugbilder sortieren.** Bilder lassen sich am Griff ziehen oder mit den Pfeilen verschieben. Die Reihenfolge bleibt nach dem Speichern erhalten. Der Stern wählt das Hauptbild separat.
- **Unterlagen gemeinsam bearbeiten.** Die Auswahl lässt sich als ZIP herunterladen. Vor dem Sammellöschen zeigt RailKeeper die betroffenen Dateien an und fragt nach Bestätigung.
- **Direkter Mehrfachupload.** „Bilder hinzufügen“ und „Unterlagen hinzufügen“ im Fahrzeug-Kurzmenü öffnen die passende Dateiauswahl.
- **Aktualisieren und sichern.** Eine Sicherung vor dem Upgrade erlaubt die Rückkehr zu v0.2.0. v0.3.0 liest ältere unterstützte Sicherungen sowie Format 29 mit den Setinhalten. Für Format 29 wird mindestens v0.3.0 benötigt.

## English

- **Accessory sets with contents.** Record track sets and other accessory packs independently of vehicles. Each component has a name and quantity per set. Stock counts complete sets.
- **Vehicle image order.** Drag the handle or use the arrow buttons to move an image. Saving preserves the new order. The star selects the main image separately.
- **Work with selected documents.** Download selected files in one ZIP. Before deleting a selection, RailKeeper lists the affected files and asks for confirmation.
- **Direct multi-file uploads.** “Add images” and “Add documents” in the vehicle quick menu open the corresponding file picker.
- **Upgrading and backups.** Take a backup before upgrading if you may need to return to v0.2.0. v0.3.0 reads previously supported backups and format 29, which stores set contents. Reading format 29 requires v0.3.0 or later.
