# RailKeeper v0.1.20.3

## Deutsch

RailKeeper 0.1.20.3 erweitert den Digitalzentralen-Arbeitsbereich um einen sicheren, vollständig
read-only Märklin-CS3-Import. RailKeeper erkennt die aktuellen und älteren Loklisten-Endpunkte,
liest UID, Name, Decoderadresse und Protokoll in eine prüfbare Vergleichsarbeitsliste und schreibt
nichts auf die Zentrale. Neue CS3-Fahrzeuge können anschließend korrekt angelegt oder einem
bestehenden RailKeeper-Fahrzeug zugeordnet werden.

CS3-Ziele sind auf private Adressen im lokalen Netzwerk begrenzt. Öffentliche, Loopback-,
Link-Local- und gemischte DNS-Ziele werden abgewiesen, DNS-Ergebnisse gegen Rebinding fest gebunden
und HTTP-Weiterleitungen nicht verfolgt.

Der CSV-Import erkennt nun vollständige Fahrzeugsets einschließlich Mitgliedschaften und
individueller Bezeichnungen. Setdaten bleiben beim Ersetzen erhalten und werden vor der Übernahme
sichtbar geprüft. Persistente Spaltenbreiten, stabile Tabellenachsen, eine robustere mobile
Fahrzeugansicht und zugänglichere Pflichtfeldhinweise verbessern die tägliche Arbeit.

Zusätzlich bringt das Release eine Stammdaten-Massendeaktivierung, präzisere Statusmeldungen der
Artikelsuche, konsolidierte Design-Tokens und Typografie, reduzierte Bewegung sowie aktualisierte
OpenSSL-Pakete im Container-Image.

Weitere Details stehen im
[deutschen Änderungsprotokoll](https://github.com/ichwars/RailKeeper/blob/v0.1.20.3/CHANGELOG.de.md).

## English

RailKeeper 0.1.20.3 adds a secure, fully read-only Märklin CS3 import to the Digital centers
workspace. RailKeeper detects current and legacy roster endpoints, reads UID, name, decoder
address, and protocol into a reviewable comparison work list, and writes nothing to the command
station. New CS3 locomotives can then be created correctly or assigned to an existing RailKeeper
vehicle.

CS3 targets are restricted to private addresses on the local network. Public, loopback,
link-local, and mixed DNS targets are rejected, DNS results are pinned against rebinding, and HTTP
redirects are not followed.

CSV import now recognizes complete vehicle sets, including memberships and individual member
labels. Set data survives replacement and remains visible for review before apply. Persistent
column widths, stable table axes, a more robust mobile inventory, and accessible required-field
cues improve daily use.

The release also adds bulk deactivation for master data, more accurate article-search status
messages, consolidated design tokens and typography, reduced-motion handling, and updated OpenSSL
packages in the container image.

See the
[English changelog](https://github.com/ichwars/RailKeeper/blob/v0.1.20.3/CHANGELOG.md)
for details.
