# Intent

Issue #33 wird lokal mit einem sicheren, versionierten Austauschformat für Gleisbibliotheken
abgeschlossen. Importdaten bleiben bis zu einer dokumentierten Admin-Prüfung unvertrauenswürdig.
Bereits platzierte Geometrien dürfen durch spätere Status- oder Versionsänderungen nicht verändert
werden.

Die Umsetzung umfasst Domänenvalidierung, Migration und Backups, Backend-Workflow, API und
OpenAPI, Planeroberfläche, Rollen und eine reale Browserabnahme. Proprietäre Fremdformate ohne
belastbare Spezifikation bleiben ausdrücklich außerhalb des Umfangs.
