# Your first vehicle

**Goal:** Add a locomotive or coach and find it again later. You do not need a command station or
CV file yet. Sign in with an **Admin** or **Editor** account. **Viewer** accounts can browse inventory.


<GuideFigure name="vehicles" alt="A small demo inventory with individual vehicles and a set." caption="A small demo inventory with individual vehicles and a set. Synthetic demo data, not factory settings. Click for full size." />

## 1. Open RailKeeper

Open the address of your installation in a browser. This address was chosen during installation.
If you see **Initial setup**, create the administrator account first. If you see **Sign in**, use an
existing account. RailKeeper has no default password. [Sign-in help](getting-started/).

## 2. Add a locomotive or coach

1. Open **Vehicle inventory** in the sidebar.
2. Select **New vehicle** and the appropriate vehicle type.
3. Enter manufacturer, name, and gauge. Choose the category and type that match the model.
4. Choose **Continue to article data**, then continue to **Vehicle details** with or without a search. Enter the details you know.
5. Select **Create**. Use **Save changes** for later edits. RailKeeper assigns an inventory number using the configured scheme.

**Result:** Your vehicle appears in inventory. If numbering is unavailable, an Admin or Editor can
check the matching inventory-number scheme under **Settings > General > Inventory numbers**.
[All vehicle fields](vehicles/).

## 3. Find the vehicle again

Search inventory by name, inventory number, or article number. Open the detail view to look up
information, or **Edit** to change it. An active filter can hide vehicles; clear it if a saved vehicle
seems to have disappeared.

## Before entering more records

Ask the operator to create an initial backup. An inventory export and a full application backup
serve different purposes. The [backup guide](../administration/backup-restore) explains both backup
and recovery.

Handbook pictures use synthetic demonstration data. Their names and CV values are not factory
settings or purchasing recommendations.
