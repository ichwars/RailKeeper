## Die wichtigsten Begriffe

| Begriff | Einfach erklärt |
| --- | --- |
| Inventarnummer | Deine eindeutige Kennung für ein Bestandsstück; nicht die Artikelnummer des Herstellers |
| Artikelnummer | Kennung des Produkts beim Hersteller; mehrere Bestandsstücke dürfen dieselbe haben |
| Fahrzeugnummer | Aufgedruckte Betriebsnummer, zum Beispiel 218 123-4 |
| Digitaladresse | Adresse, mit der die Zentrale den Decoder anspricht |
| Decoderprofil | Belegte Regeln für ein bestimmtes Decodermodell; ein Hersteller allein reicht nicht für jede CV |
| CV | Eine nummerierte Decodereinstellung; Rohwert und Erklärung sind verschiedene Informationen |
| Indexseite | Zusätzliche Adressierung über CV31/CV32; dieselbe CV-Nummer kann dort andere Werte und Bedeutungen besitzen |
| Herkunft | Beleg, woher ein Wert stammt, etwa Exportdatei, Originalzeile oder Zentrale |
| Schaltart | Dauerfunktion bleibt ein-/ausgeschaltet; Momentfunktion ist als Taster vorgesehen |
| Invertierung | Umkehr der beschriebenen Funktion; unabhängig von der Fahrtrichtung |
| Transferprofil | Wiederverwendbare Auswahl für einen Import oder Export |
| Anwendungssicherung | Wiederherstellbare App-Daten samt Medien, ohne lokale Benutzerkonten und Sitzungsschlüssel |
| Server | Der Rechner, auf dem RailKeeper läuft; bei Fernzugriff nicht zwingend dein Browser-PC |

## Tastatur und Bilder

Mit Tab wechselst du zwischen Bedienelementen, mit Enter aktivierst du Schaltflächen. Escape schließt viele Dialoge; lies vor dem Verlassen Hinweise auf ungespeicherte Änderungen. Handbuchbilder lassen sich über einen Klick in voller Größe öffnen. Suche oben im Handbuch nach einem Begriff oder einer Aufgabe.
