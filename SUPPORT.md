# Support

RailKeeper is maintained as a free, self-hosted open-source project.

- Report reproducible defects through [GitHub Issues](https://github.com/ichwars/RailKeeper/issues).
- Discuss usage questions and feature ideas in
  [GitHub Discussions](https://github.com/ichwars/RailKeeper/discussions).
- Report vulnerabilities only through the private process described in [SECURITY.md](SECURITY.md).

Support is provided as maintainer capacity permits. There is no service-level agreement, guaranteed
response time, individual support entitlement, or commitment to implement a requested feature.

Voluntary tips through GitHub Sponsors or Ko-fi support project-related costs. A tip is not a
purchase and creates no entitlement to software, features, support, response times, influence, or
special access.
